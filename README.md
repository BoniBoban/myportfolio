# Boniface Boben — GitHub Pages Portfolio

A responsive static portfolio built with HTML, CSS and JavaScript. No framework, build process or paid hosting is required.

## Files
- `index.html` — page content
- `style.css` — design, colours and responsive layout
- `script.js` — mobile navigation and automatic footer year
- `assets/boniface-profile.jpg` — temporary portrait crop from the screenshot provided
- `assets/portfolio-design-reference.png` — generated visual mock-up

## Before publishing
1. Replace `assets/boniface-profile.jpg` with your original, high-resolution portrait (keep the filename).
2. Add your CV PDF into `assets/` and name it `Boniface_Data_Analyst.pdf`. The Download CV button expects this exact filename.
3. Verify your email, phone, GitHub and LinkedIn links.
4. Verify dashboard links and confirm the reports are publicly shareable.
5. Review the experience and certification wording for accuracy.

## Preview locally
Open `index.html` in a browser. For a better workflow, open this folder in Visual Studio Code, install the **Live Server** extension, right-click `index.html`, and select **Open with Live Server**.

## Publish with GitHub Pages
1. Sign in to GitHub. Create a **public** repository named `boniboban.github.io` (replace `boniboban` with your exact GitHub username if different).
2. Unzip this project and upload the *contents* of the `boniface-portfolio` folder to the repository root. `index.html` must be at the top level.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish. The expected address is `https://boniboban.github.io/` if the username/repository match.
7. Future commits or uploads to `main` will update the website.

## Customise
- Change theme colours at the top of `style.css` in the `:root` section.
- Edit wording, project details and links in `index.html`.
- Edit mobile menu behaviour in `script.js`.

**Note:** the portrait is only a crop from the screenshot and should be replaced with the original photo before going live. Add the CV PDF before relying on the download button.
